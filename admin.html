Siap dibagikan
Terbitkan perubahan dan simpan salinan draf Anda.
Simpan draf ≠ terbitkan.
Draf dan daftar tamu hanya tersimpan di browser ini. Agar perubahan dilihat tamu, unduh paket pembaruan dan unggah isinya ke repository GitHub.
1. Periksa undangan
Lengkapi formulir lalu buka pratinjau. Nama tamu contoh: Bapak Ahmad & Ibu Siti.
2. Unduh paket pembaruan
Berisi index.html, data.js, dan foto/musik unggahan. Gabungkan dengan paket utama; ini bukan website mandiri. Daftar tamu tidak ikut diterbitkan.
3. Unggah ke GitHub
Ekstrak ZIP. Timpa file yang sama di repository, lalu commit. Setelah GitHub Pages selesai, periksa tautan publik sebelum membagikannya.
